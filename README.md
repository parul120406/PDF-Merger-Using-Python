# PDF Merger Using Python

A simple Python project that combines multiple PDF files into a single PDF using the PyPDF2 library.

## Features

* Merge multiple PDF files
* User-friendly input system
* Creates a single merged PDF file
* Uses the PyPDF2 library

## Technologies Used

* Python 3
* PyPDF2

## How It Works

1. Enter the number of PDF files to merge.
2. Enter the names of the PDF files.
3. The program combines all PDFs.
4. A new file named `merged_pdf.pdf` is created.

## Example

Input:

```
How many pdfs do you want to merge?
3

Enter the name of pdf 1: pdf1.pdf
Enter the name of pdf 2: pdf2.pdf
Enter the name of pdf 3: pdf3.pdf
```

Output:

```
PDFs merged successfully!
```

